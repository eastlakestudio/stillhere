# 微信小程序 UI 规范（内置模板）

> 来源：openpoc review ui 内置模板
> 终端：微信小程序（MiniApp）
> 生成时间：2026-07-20

## 1. 布局规范

| 区域 | 规格 | 说明 |
|------|------|------|
| 顶部导航栏 | 高度 44-48px，全宽 | 返回按钮 + 页面标题（居中），可配置背景色和文字色 |
| 搜索栏 | 高度 36-44px | 搜索框 + 取消按钮，可在导航栏下方或页面内 |
| 内容区 | 剩余高度（不含 TabBar 和安全区） | 纵向滚动，scroll-view 包裹 |
| 底部 TabBar | 高度 50-56px + 安全区 | 2-5 个 Tab，图标 + 文字，可带 Badge（原生或自定义） |
| 胶囊按钮区 | 右上角固定 | 微信原生胶囊（··· + 〇），不可覆盖，页面布局需避开 |

## 2. 视觉风格

- **设计语言**：微信原生风格（WeUI 设计体系），简洁克制
- **背景色**：页面底色 #f6f6f6（微信默认），Card 底色 #ffffff
- **主色调**：微信绿 #07c160 或品牌色（通过 app.json 全局配置导航栏颜色）
- **功能色**：成功绿 #07c160、警告橙 #fa8c16、危险红 #fa5151、链接蓝 #576b95
- **字体**：标题 16-17px（加粗），正文 14-15px，辅助文字 12px（#888）
- **圆角**：Card 4-8px（小程序默认圆角偏小），按钮 4px
- **分割线**：1px solid #e5e5e5，仅在列表项间使用（1px 物理像素 = 0.5px 逻辑像素）
- **阴影**：谨慎使用，小程序性能对阴影敏感，优先用边框替代
- **禁用**：过大圆角（>12px）、复杂阴影、非系统字体、横屏布局（小程序默认竖屏）

## 3. 组件规范

| 组件 | 说明 |
|------|------|
| 原生导航栏 | `app.json` 全局配置，支持透明/指定颜色，页面级可覆盖标题和颜色 |
| view 容器 | 对应 `<div>`，支持 flex 布局，scroll-view 用于可滚动区域 |
| text 文本 | 对应 `<span>`，支持 selectable/user-select 属性，长按可选中复制 |
| image 图片 | 支持懒加载 `lazy-load`，mode 属性控制裁剪模式（aspectFill/aspectFit） |
| button 按钮 | 原生 button 组件，支持 open-type（分享/获取手机号/打开设置等微信能力） |
| input 输入框 | 原生 input 组件，type 支持 text/number/idcard/digit，focus 自动调整键盘 |
| textarea 多行输入 | 原生 textarea，支持自动增高 `auto-height`，show-confirm-bar 控制完成栏 |
| picker 选择器 | 原生底部滚轮选择器，支持普通/多列/时间/日期/省市区模式 |
| modal 弹窗 | `wx.showModal` API，原生样式，含标题/内容/确定取消；或自定义 view 弹窗 |
| toast 提示 | `wx.showToast` API，支持 success/error/loading/none 四种 icon |
| loading 加载 | `wx.showLoading` API 或骨架屏（自定义 view 模拟） |
| switch 开关 | 原生 switch 组件，支持自定义颜色 |
| slider 滑块 | 原生 slider 组件，支持范围、步长、颜色 |
| map 地图 | 原生 `<map>` 组件，支持标记点 markers、路线 polyline、圆形/多边形覆盖物 |
| swiper 轮播 | 原生 `<swiper>` + `<swiper-item>`，支持自动播放、指示点样式 |
| form 表单 | 原生 form 组件，`bindsubmit` 统一收集表单数据 |
| icon 图标 | 内置 WeUI 图标集，或自定义 iconfont/字体图标，建议尺寸 20-24px |

## 4. 分辨率与兼容性

| 指标 | 要求 |
|------|------|
| 基准分辨率 | 375×812 (iPhone X，微信默认逻辑分辨率) |
| 适配范围 | 宽度 320-428px，rpx 自动适配（750rpx = 屏幕宽度） |
| 微信版本 | 微信 8.0+，基础库 2.20+ |
| 操作系统 | iOS 15+ / Android 10+ |
| 包体积 | 单包 ≤ 2MB，分包总 ≤ 20MB（含插件），静态资源建议上 CDN |
| 并发限制 | wx.request 并发最多 10 个，WebSocket 最多 2 个 |
| 组件限制 | 页面栈最多 10 层，超限用 `wx.redirectTo` 替代 `wx.navigateTo` |

## 5. 交互规范

- **导航**：底部 TabBar 切换一级页面（2-5 个），`wx.navigateTo` 进入子页面（保留返回），`wx.redirectTo` 替换当前页
- **返回**：左上角返回按钮（原生），Android 物理返回键同样触发返回
- **下拉刷新**：页面级 `enablePullDownRefresh` + `onPullDownRefresh`，刷新动画为原生风格
- **触底加载**：`onReachBottom` 触底事件，配合 `lower-threshold` 设置触发距离
- **分享**：右上角 `···` 菜单中"转发"，需实现 `onShareAppMessage` 自定义分享标题和图片
- **扫码**：`wx.scanCode` API 调用摄像头扫码（二维码/条形码），结果返回后自行处理
- **授权**：用户信息、地理位置、相册等需 `wx.authorize` 或 `<button open-type>` 引导授权
- **表单提交**：form `bindsubmit` 统一收集，提交按钮需防重复点击，成功后 Toast + 返回
- **空状态**：无数据时展示空状态插画 + 引导文案 + 操作按钮（如"去添加"）
- **错误状态**：网络异常展示 `wx.showModal` 重试提示；接口错误展示 Toast；全局使用 `wx.onNetworkStatusChange` 监听
- **性能**：避免频繁 setData（合并更新）、避免过大 data 对象、长列表使用虚拟列表
- **深色模式**：`wx.getSystemInfo` 获取 `theme` 字段，支持 DarkMode 切换配色（基础库 2.20+）
- **无障碍**：aria-label 属性、`aria-role` 语义化，支持系统读屏
