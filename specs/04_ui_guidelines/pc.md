# PC 管理后台 UI 规范（内置模板）

> 来源：openpoc review ui 内置模板
> 终端：PC Web
> 生成时间：2026-07-20

## 1. 布局规范

| 区域 | 规格 | 说明 |
|------|------|------|
| 顶部导航 | 高度 56px，全宽 | Logo + 场景Tab + 通知 + 用户 + 设置 |
| 左侧菜单 | 宽度 220px，固定 | 场景列表，支持按角色过滤，可以扩展收缩 | 
| 主内容区 | 剩余宽度，iframe 嵌入 | 场景页面渲染区域 |
| 底部状态栏 | 高度 32px，全宽 | 系统状态 / 当前场景 / 在线用户 / 终端 |
| 面包屑 | 顶部导航下方 | 当前页面路径导航 |

## 2. 视觉风格

- **设计语言**：白色简约风（Draft 阶段）
- **配色**：白底 + 1px 细线边框（#e0e0e0），无阴影无圆角
- **按钮**：线框样式（border + 白底），hover 加深边框
- **表格**：简单边框，表头浅灰底（#f5f5f5）
- **地图占位**：虚线边框 Card（.map-placeholder），居中标注「地图区域」
- **图片占位**：虚线边框 Card（.img-placeholder），居中标注「图片占位」
- **禁用**：彩色按钮 / 渐变 / box-shadow / border-radius

## 3. 组件规范

| 组件 | 说明 |
|------|------|
| Card | card-header + card-body，白底 + 1px 边框 |
| Table | 简单边框线，表头浅灰底，数据行 hover 高亮 |
| Form | label 左对齐，input/select/textarea 线框样式 |
| Button | 线框按钮（主操作加深边框），禁用态灰色文字 |
| Modal | 居中弹出层，半透明遮罩，1px 边框 |
| Panel | 右侧滑出详情面板（v-if 控制），宽度 400px |
| Tab | 下划线式切换，active 加粗 |
| Badge/Tag | 线框标签，文字+边框同色 |
| Breadcrumb | 顶部面包屑，`>` 分隔 |

## 4. 分辨率与兼容性

| 指标 | 要求 |
|------|------|
| 基准分辨率 | 1920×1080 |
| 最低分辨率 | 1366×768 |
| 浏览器 | Chrome / Firefox / Edge 最新 2 个版本 |

## 5. 交互规范

- 侧栏菜单点击 → 切换主内容区 iframe
- 面包屑点击 → 返回上级场景
- 按钮 click → 触发对应动作（弹窗/跳转/刷新列表）
- Tab 切换 → 切换内容面板
- Panel 滑出 → 右侧覆盖，带遮罩
- 表单提交 → 校验 → 确认弹窗 → 更新列表
