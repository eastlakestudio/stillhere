# 大屏态势监控 UI 规范（内置模板）

> 来源：openpoc review ui 内置模板
> 终端：大屏（Big Screen）
> 生成时间：2026-07-20

## 1. 布局规范

| 区域 | 规格 | 说明 |
|------|------|------|
| 顶部标题栏 | 高度 60-80px，全宽，居中 | 平台名称 + 日期时间 + 天气 + Logo |
| 左侧指标区 | 宽度 25-30%，纵向排列 | 关键 KPI Card（2-4 个），数值大字体突出 |
| 中央主视图 | 剩余宽度 40-50% | 地图 / 3D 场景 / 核心业务大图 |
| 右侧详情区 | 宽度 25-30%，纵向排列 | 实时列表 / 趋势图表 / 告警信息 |
| 底部滚动条 | 高度 40-50px，全宽 | 滚动通知 / 实时事件播报 |

```
┌─────────────────────────────────────────────────────┐
│           顶部标题栏 (80px)  平台名称 + 时间          │
├──────────┬──────────────────────┬──────────────────┤
│ 指标Card  │                      │  实时告警列表      │
│ 指标Card  │    地图 / 主视图       │  趋势折线图        │
│ 指标Card  │                      │  排行榜           │
│ 指标Card  │                      │                   │
├──────────┴──────────────────────┴──────────────────┤
│          底部滚动信息条 (40px)  事件播报               │
└─────────────────────────────────────────────────────┘
```

## 2. 视觉风格

- **设计语言**：深色科技风（Dark Tech）
- **背景色**：底色 #0a1628，卡片底色 #0d1f3c，边框 #1a3a5c
- **数据色**：高亮蓝 #00d4ff、告警红 #ff4d4f、警告黄 #faad14、正常绿 #52c41a
- **字体**：标题 28-40px，数值 48-72px（加粗），正文 14-16px
- **装饰**：边框发光效果（box-shadow: 0 0 10px rgba(0,212,255,0.3)）、顶部/左侧装饰线
- **卡片**：半透明深色背景 + 1px 发光边框，四角装饰小三角
- **图标**：线性图标为主，2px 描边，与数据色匹配
- **禁用**：白色背景、大面积亮色、圆角过大（不超过 4px）

## 3. 组件规范

| 组件 | 说明 |
|------|------|
| 指标Card | icon + 指标名 + 数值（大字体）+ 同比环比箭头，hover 边框发光增强 |
| 图表 | ECharts / DataV 图表组件，深色主题配色，无网格线或浅色网格线 |
| 实时列表 | 表头固定 + 自动滚动，新数据行高亮闪烁 2s 后恢复 |
| 地图 | Cesium/Leaflet/百度 地图引擎，深色地图主题，聚合点标记 + 信息窗 |
| 告警面板 | 右下方悬浮或右侧固定，按等级分色，点击展开详情 |
| 进度条/仪表盘 | 深色底 + 渐变色填充，带动画效果 |
| 标签/Badge | 半透明背景 + 边框，小圆角 |
| 时间选择器 | 下拉或时间轴拖拽，深色主题适配 |

## 4. 分辨率与兼容性

| 指标 | 要求 |
|------|------|
| 基准分辨率 | 3840×1080  |
| 兼容分辨率 | 1920×1080 (Full HD) |
| 屏幕类型 | LED 拼接屏 / 液晶大屏 |
| 浏览器 | Chrome 最新版（建议全屏 Kiosk 模式）|
| 刷新频率 | 关键指标 1-3s 刷新，图表 5-10s 刷新 |

## 5. 交互规范

- 默认自动轮播：无操作时每 30-60s 切换视图/场景
- 点击指标 Card → 中央主视图联动切换
- 点击地图标记 → 右侧弹出详情面板
- 告警触发 → 顶部/右侧高亮闪烁 + 声音提示（可选）
- 多屏联动：主屏 + 副屏（2-4 块）协同展示不同维度的数据
- 键盘快捷键：F11 全屏、数字键 1-9 切换场景、ESC 退出全屏
- 数据回放：时间轴拖拽，回放历史某一时刻的状态
