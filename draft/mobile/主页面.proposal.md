## 二、字段清单

| 字段 | 类型 | 说明 |
|------|------|------|
| myCareCode | String | 我的 6 位关心码，如 "A1B2C3" |
| caredByCount | Number | 关注我的人数 |
| timeWindowSummary | String | 守护时段摘要，如 "2个时段 · 共9小时" |
| isAlerted | Boolean | 是否处于告警状态 |
| pendingAlertMinutes | Number/null | 告警倒计时剩余分钟数 |
| caringList | Array\[Object\] | 我关心的人列表 |
| caringList\[i\].nickname | String | 本地昵称 |
| caringList\[i\].bindCode | String | 对方关心码（6位） |
| caringList\[i\].lastActive | String | 最近活跃时间文案，如 "刚刚" / "5分钟前" |
| caringList\[i\].isCharging | Boolean | 是否充电中 |
| caringList\[i\].city | String/null | IP 归属城市 |
| caringList\[i\].isMutual | Boolean | 是否互相关心 |

## 三、交互清单

| 交互 | 触发 | 行为 |
|------|------|------|
| 查看二维码 | 点击 [查看二维码] | 弹出关心码二维码 Sheet |
| 分享关心码 | 点击 [分享] | 弹出分享操作菜单 |
| 查看关心我的人 | 点击 [查看详情 >] | 跳转「谁在关心我」页面 |
| 添加关心 | 点击 [添加关心] | 弹出添加关心 Sheet（扫码/手动输入） |
| 守护时段 | 点击 [守护时段] | 跳转守护时段配置页 |
| 问安 | 点击 [问安 >] | 弹出问安 Sheet，发送问安消息 |
| 关心详情 | 点击关心对象卡片 | 弹出关心对象详情 Sheet |
| 取消告警 | 点击 [取消告警] | 取消当前告警倒计时 |
| 下拉刷新 | 列表顶部下拉 | 刷新关心对象状态 |

## 四、边界状态

| 状态 | 表现 |
|------|------|
| 无人关心我 | caredByCount = 0，卡片文案 "暂无人在关心我" |
| 无关心对象 | caringList 为空，显示空状态 "还没有添加关心的人，点击上方添加" |
| 无守护时段 | timeWindowSummary 显示 "未配置守护时段，全天监测" |
| 充电中 | isCharging = true，卡片显示 ⚡ 图标 |
| 未活跃 | lastActive 为 null，显示 "暂无活动数据" |
| 告警中 | 顶部红色 Banner 显示倒计时 + 取消按钮 |
