# 我的关心码 — Draft 线框方案

> 场景：我的关心码  
> 终端：mobile  
> 版本：V1.0

## 一、页面结构

```
┌──────────────────────────────┐
│  状态栏 (时间/电量/信号)        │
├──────────────────────────────┤
│  ← 返回       标题          │  ← 导航栏
├──────────────────────────────┤
│                              │
│      ┌──────────────────┐    │
│      │                  │    │
│      │   QR Code 二维码   │    │  ← 二维码占位（虚线边框）
│      │   200×200         │    │
│      │                  │    │
│      └──────────────────┘    │
│                              │
│     关心码：A1B2C3            │  ← 大号居中显示
│                              │
│   ┌──────────────────────┐   │
│   │      [分享关心码]       │   │  ← 主按钮
│   └──────────────────────┘   │
│                              │
├──────────────────────────────┤
│  提示：将此页面展示给对方，     │
│  对方扫码或输入以上6位码即可    │
│  添加你为关心对象。            │
├──────────────────────────────┤
│                              │
│  ┌──────────────────────────┐│
│  │ 绑定时间：2026-07-20      ││  ← 信息卡片
│  │ 被 3 人关心              ││
│  └──────────────────────────┘│
│                              │
└──────────────────────────────┘
```

## 二、字段清单

| 字段 | 类型 | 说明 |
|------|------|------|
| careCode | String | 我的 6 位关心码 |
| caredByCount | Number | 关心我的人数 |
| bindDate | String | 注册日期 |

## 三、交互清单

| 交互 | 触发 | 行为 |
|------|------|------|
| 返回 | 点击 ← | 返回上一页 |
| 分享关心码 | 点击 [分享关心码] | 弹出系统分享面板（文本 + 图片） |
| 长按二维码 | 长按 QR 区域 | 保存 / 分享二维码图片 |

## 四、边界状态

| 状态 | 表现 |
|------|------|
| 无人关心 | caredByCount = 0，显示 "暂无人在关心你" |
| 新注册 | bindDate = 当天，显示 "今天" |
