## 二、视觉设计

### 2.1 设计系统

| 设计令牌 | 值 | 用途 |
|----------|-----|------|
| 主色 Primary | `#C25A00` | 按钮、链接、强调色 |
| 主色容器 Primary Container | `#FFF3E8` | 次要按钮背景 |
| 表面色 Surface | `#FFF8F4` | 页面背景（暖色调） |
| 表面容器 Surface Container | `#F3EDF7` | 卡片背景 |
| 轮廓 Outline | `#E7E0EC` | 边框、分割线 |
| 错误色 Error | `#B3261E` | 告警横幅、删除操作 |
| 成功色 Success | `#52C41A` | 恢复通知 |
| 文字主色 On Surface | `#1C1B1F` | 正文 |
| 文字辅色 On Surface Variant | `#49454F` | 辅助文字 |
| 不可用色 Disabled | `#999` | 提示文字、placeholder |

### 2.2 字体排版

| 样式 | 用途 | 字号 | 字重 |
|------|------|------|------|
| 标题 | App 标题 "晴好" | 20px | 300 (Light) |
| 页面标题 | 页面级标题 | 20px | 300 |
| 卡片标题 | Card Title | 16px | 500 |
| 正文 | 一般内容 | 14-15px | 400 |
| 辅助文字 | 次要信息 | 12-13px | 400 |
| 关心码 | 6 位码展示 | 32px | 300 (monospace) |

### 2.3 圆角与阴影

| 元素 | 圆角 | 阴影 |
|------|------|------|
| 手机外框 | 36px | `0 20px 60px rgba(0,0,0,0.3)` |
| 屏幕区域 | 0 0 28px 28px | 无 |
| 卡片 | 无 | 无（用背景色区分） |
| 按钮 | 无 | 无 |

## 三、组件选型

| 组件 | 实现方式 | 说明 |
|------|----------|------|
| 手机外框 | 纯 CSS `div.phone-frame` | 390px 宽，深空灰中框 |
| 状态栏 | 纯 CSS `div.phone-status-bar` | 24px 黑色通栏，含时间/信号图标 |
| 导航栏 | 纯 CSS `div.app-header` | 56px 高，左返回右标题 |
| 卡片 | 纯 CSS `div.card` | 填充背景色区分的矩形块 |
| 按钮 | 纯 CSS `button` | 实色填充（Primary）或 Outline |
| 输入框 | 原生 `input` | 1px 实边，关心码输入用 monospace 字体 |
| 滑块 | 原生 `input[type=range]` | 守护时段阈值配置 |
| 开关 | 纯 CSS toggle | 复选框模拟 |
| 二维码 | 占位 `div` | 200×200 虚线占位区域 |
| 扫描区 | 占位 `div` | 虚线边框相机区域 |
| 空状态 | 纯 CSS 提示文案 | 无数据时的引导 |
| 弹窗 | 原生 `alert()` / `confirm()` | 简化交互反馈 |
| 底部导航条 | 纯 CSS `div.phone-nav-bar` | 模拟安卓手势导航条 |

> 地图配置：本项目为移动端安全监测 App，无地图模块，不涉及地图引擎选型。

## 五、交互规范

### 5.1 导航

| 操作 | 行为 |
|------|------|
| 场景地图入口点击 | 跳转对应 HTML 页面 |
| 导航栏 ← 按钮 | 返回场景地图 (index.html) |
| 底部返回链接 | 返回场景地图 (index.html) |
| 卡片整体点击 | 跳转详情页（`event.stopPropagation` 处理内嵌按钮） |

### 5.2 数据展示

| 状态 | 表现 |
|------|------|
| 加载中 | 无（静态原型） |
| 空状态 | 显示引导文案 |
| 告警中 | 红色边框横幅 + 倒计时 + 取消按钮 |
| 已恢复 | 绿色主题色边框卡片 |
| 互相关心 | "互关" Badge (`#C25A00` 边框) |
| 充电中 | ⚡ 图标显示 |

### 5.3 反馈

| 操作 | 反馈 |
|------|------|
| 提交按钮 | `alert()` 弹出确认提示 |
| 删除操作 | `confirm()` 确认对话框 |
| 分享/扫码 | `alert()` 模拟系统行为 |
