## 🖥️ 终端与平台

| 终端 | 平台 | 说明 |
|------|------|------|
| 移动端 | iOS | Swift 6 + SwiftUI，iOS 17.0+ |
| 移动端 | Android | Kotlin + Jetpack Compose (Material 3)，API 26+ |
| 服务端 | Cloudflare Workers | TypeScript + D1 (SQLite) |

## 🗺️ 终端 × 业务场景

| 终端 | 场景 | 说明 | 来源 |
|------|------|------|------|
| iOS / Android | 生成关心码 | App 首次启动生成 Device ID 和关心码，可展示二维码供对方扫描 | 2.1 设备身份 |
| iOS / Android | 添加关心 | 扫码或手动输入 6 位关心码，建立关心关系 | 2.2 关心关系管理 |
| iOS / Android | 管理关心列表 | 查看我关心的人、关心我的人，删除关系，标记互关 | 2.2 关心关系管理 |
| iOS / Android | 活动监测 | 后台持续感知运动、位置、充电，生成活动事件 | 2.3 活动监测 |
| iOS / Android | 心跳上报 | 前台/后台定时向服务端上报心跳 | 2.4 心跳上报 |
| iOS / Android | 静置告警 | 超阈值无活动触发本地告警 + 5 分钟取消窗口 | 2.5 告警系统 |
| iOS / Android | 告警通知 | 接收告警通知（iOS APNs / Android 轮询） | 2.5 告警系统 |
| iOS / Android | 发送问安 | 关心者向被关心者发送问安消息 | 2.6 问安 |
| iOS / Android | 回复问安 | 收到问安后快捷回复或自定义文本回复 | 2.6 问安 |
| iOS / Android | 状态查询 | 查看被关心者的最近活跃时间、充电状态、IP 城市 | 2.7 状态查询 |
| iOS / Android | 守护时段配置 | 配置多个守护时段，仅时段内触发告警 | 2.3 活动监测 |
| Server | 心跳接收 | 接收客户端心跳，更新 lastActiveTime | 2.4 心跳上报 |
| Server | 关系管理 API | /care 创建/删除关心关系 | 2.2 关心关系管理 |
| Server | 状态查询 API | /cared-status 批量查询被关心者状态 | 2.7 状态查询 |
| Server | 告警管理 API | /alert /alert/cancel 管理告警生命周期 | 2.5 告警系统 |
| Server | 问安管理 API | /greeting /greeting/reply 管理问安消息 | 2.6 问安 |
| Server | 离线检测 | Cron 每 5 分钟检测超 24 小时无心跳用户 | 2.5 告警系统 |
